## Project Overview

This project uses machine learning to predict whether passengers aboard the Spaceship Titanic were transported to an alternate dimension.

## Objectives

- Explore and understand the passenger dataset.
- Perform data preprocessing and feature preparation.
- Train and evaluate classification models.
- Generate predictions for the Kaggle test dataset.
- Maintain project files and development history using Git and GitHub.

## Technologies Used

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook
- Git and GitHub
